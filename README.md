# The Ministry of Nails — Premium React Website

A responsive multi-page React + Vite website for The Ministry of Nails, Purnea. The original company logo (`public/img/logo.png`) and supplied studio photography are retained.

## Pages
- `/` — Home
- `/about` — Our Story
- `/services` — Services
- `/gallery` — Gallery with keyboard-accessible lightbox controls
- `/contact` — Contact

## Start locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Included
- React Router and responsive navigation
- GSAP + ScrollTrigger reveal, stagger and parallax motion
- Lenis smooth scrolling synchronised with GSAP
- Magnetic / elastic hover movement on selected interactive elements
- Responsive editorial layouts and the original supplied photography
- WhatsApp appointment links
- Reduced-motion accessibility support
